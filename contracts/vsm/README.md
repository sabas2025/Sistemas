# Contratos VSM

Armazene aqui as cópias **homologadas e aprovadas** dos documentos OpenAPI/Swagger da VSM.

Nomes recomendados:

- `pedidos-integradora.openapi.json`
- `pedidos-loja.openapi.json`

O HUB não inclui uma especificação inventada. O arquivo oficial deve ser exportado do Swagger da VSM e validado com `VsmOpenApiContractService`. A validação é somente leitura e não executa pedidos, estoque ou operações fiscais.

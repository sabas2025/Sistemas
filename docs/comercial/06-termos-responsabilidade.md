# Termos de responsabilidade

O HUB é uma camada de integração. Ele não substitui validação fiscal, responsabilidade contábil, emissão oficial da NF-e pelo sistema autorizado nem a obrigação do cliente de manter dados corretos.

## Limites
- O HUB depende de APIs externas.
- Falhas de Tiny, VSM, ERP, marketplace, hospedagem, DNS, SSL ou internet podem afetar o fluxo.
- O cliente deve homologar pedidos, produtos, estoque e fiscal antes de produção.

## Dados sensíveis
Tokens, senhas, chaves HMAC e dados fiscais devem ser tratados como confidenciais.

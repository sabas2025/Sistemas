# Compatibilidade do Hub

| Plataforma | Forma de uso |
|---|---|
| Android | PWA instalável pelo Chrome ou Edge |
| iPhone/iPad | Safari → Compartilhar → Adicionar à Tela de Início |
| Windows | Instalação pelo Edge ou Chrome |
| macOS | Instalação pelo Safari, Chrome ou Edge |
| Navegador | Sistema web responsivo |

## Segurança do PWA
O service worker não armazena dashboard, pedidos, estoque, fiscal, backups, auditoria, tokens, configurações ou respostas de API. Sem internet, o Hub mostra apenas a página offline e não simula dados operacionais.
